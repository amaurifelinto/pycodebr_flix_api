**** Gerenciamento de permissões de usuários ****
Super user tem permissão para alterar o System (tabela de sistema) 
e o admin user não tem

No admin do Django, escolhe o usuário e acrescenta permissões
em Chosen user permission

Criou permissions.py em genres:
from rest_framework import permissions

class GenrePermissionClass(permissions.BasePermission):

    def has_permission(self, request, view):
        if request.method in ['GET', 'OPTIONS', 'HEAD']:
            return request.user.has_perm('genres.view_genre')

        if request.method == 'POST':
            return request.user.has_perm('genres.add_genre')

        if request.method in ['PATCH', 'PUT']:
            return request.user.has_perm('genres.change_genre')

        if request.method == 'DELETE':
            return request.user.has_perm('genres.delete_genre')

        return False
